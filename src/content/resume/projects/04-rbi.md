Client: Restaurant Brands International | April 2022 – August 2022

Developed and enhanced an internal Restaurant Management Portal for Restaurant Brands International (RBI), enabling employees to manage user accounts, roles and permissions, restaurant equipment, training programs, and restaurant opening and closing hours. The platform also provides training modules for newly onboarded employees.

**Responsibilities:**

- Designed and implemented onboarding workflows for admin and non-admin users, improving user activation and access control.
- Developed role-based features to ensure personalized data visibility and access across different user roles.
- Created and executed UI test cases using React Testing Library to validate functionality, usability, and application quality.
- Integrated internationalization using i18next to support multilingual interfaces and application localization across 15+ languages.
