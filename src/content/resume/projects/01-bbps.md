Client: Axis Bank | September 2022 – Present

Developed and enhanced the Bharat Bill Payment System (BBPS), an integrated bill payment ecosystem conceptualized by the Reserve Bank of India (RBI) and driven by the National Payments Corporation of India (NPCI). The platform enables consumers and corporates to make bill payments through a wide network of banks, payment applications, and retail agents.

**Responsibilities:**

- Designed and developed RESTful services using Spring Boot to process JSON requests and implement backend business logic.
- Migrated backend APIs from a monolithic Spring MVC application to standalone Spring Boot services with RESTful endpoints.
- Developed dynamic frontend modules using AngularJS, HTML, CSS, and JavaScript, integrating them with backend APIs.
- Implemented server-side rendered application forms using Thymeleaf with dynamic content rendering and model binding.
- Resolved application security vulnerabilities and static code quality issues identified through Checkmarx.
- Implemented SAML-based authentication by configuring Identity Provider endpoints and deploying the solution successfully to production.
